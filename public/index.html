BEFORE YOUR FIRST VISIT

出发前的小问答。

需要下载游戏吗？

不需要。点击「进入小镇」，在支持 WebGL 的现代浏览器中打开即可。第一人称游玩推荐使用电脑、键盘和鼠标。

还不会建模，可以先逛逛吗？

可以，访客无需登录就能探索公开世界。准备建造时，再登录、领取土地，并参考建造指南让 Codex 帮你完成模型。

我的建筑提交后会马上出现吗？

模型通过尺寸和资源校验后还需要审核。审核通过才会公开；更新建筑时，旧版本会保留到新版本通过审核。

当前可以体验哪些功能？

目前可体验小镇探索、昼夜切换、水面互动，以及本机演示账号的领取、提交与审核流程。真实 GitHub 登录需由站点运营者完成配置；水波在本地计算，尚未在玩家之间同步。
