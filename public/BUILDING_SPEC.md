# openworld · Codex 建模任务规范

请为我的在线个人领地制作一个完整、原创的日系风格建筑或迷你小镇，并导出 `building.glb`。

- 地块宽 X ≤ 64 米、深 Z ≤ 64 米、建筑高 Y ≤ 600 米。建议各方向留出 1 米退界，便于观赏。
- 世界按需生成平缓街区、连续道路、河流和桥梁。街区先整平，再分配沿街地块；已领取地块的地基高度固定。600 米限高相对地基，不是海拔。不要建模周边道路和山水，网站已经提供。
- 1 glTF 单位 = 1 米，Y 轴向上。Blender 使用其默认 Z 轴向上，标准 GLB 导出会自动转换。
- 网站会按实际世界包围盒将建筑水平居中、底部贴地；网站不会自动缩小超限建筑。先应用合适的缩放。
- 文件为单一 GLB 2.0，≤12 MiB，只有一个场景。所有几何和贴图内嵌，无外链和脚本。
- 使用普通 metallic/roughness PBR 材质；暂不使用任何 glTF 扩展，包括 Unlit、Draco、Meshopt、GPU instancing、灯光扩展。不要导出相机和灯光。
- 静态三角化网格，≤100000 三角面（计入实例），≤200 个绘制单元，≤512 个节点。不导出动画、骨骼、形变目标。
- 贴图仅 PNG / JPEG，最多 16 张，单张 ≤2048×2048，总像素 ≤16777216；不要动画贴图。
- 夜晚由网站统一照明。可使用适度自发光材质表现窗户和招牌，但不要过曝。
- 模型应从街道四面都可观赏，可加入庭院、门牌、植被、围栏和建筑细节。地基和所有装饰都必须计入尺寸。
- 提交后先通过服务器技术校验，再由管理员人工审核。只有通过的版本对公众可见。
- 第一版在线散步对玩家建筑采用整体包围盒碰撞；不保证能进入室内或穿过庭院。请把关键视觉细节做在外部。

交付：`building.glb`、可编辑建模源文件、正面与鸟瞰预览图、实际长宽高和三角面数量。只有 GLB 上传到网站。

作者须有权公开使用模型与贴图；避免侵犯其他创作者权益。管理员可退回不符合世界风格或规则的内容。
# 多边形领地说明

新领取方式支持 3～8 边形，包括不自交的凹多边形。请先领取土地，再在网页中点击“下载 Codex 建模规范”，获取个人领地的精确坐标和尺寸。以下 64×64 米约束仅适用于旧矩形领地；多边形领地以个人下载规范为准。

新领地面积为 256～4096 平方米，外接长宽最多 96 米，限高 600 米。模型的每个三角面都必须位于真实轮廓内，凹角缺口不属于建筑用地。模型会按世界包围盒的水平中心放置，并将最低点贴到地基。
